System Instructions & Help Guide

Follow these instructions to navigate the Sunrise Dental Clinic Management System correctly.

1. Registering an Appointment

Go to the Register Appointment tab. Fill in all patient details accurately. Select the designated Dentist and Treatment type. The system will automatically prevent double bookings for the same dentist at the same time.

2. Viewing Appointment Details

Navigate to the View/Search Details tab. Enter the exact Appointment Number (e.g., APT-2026-0001) generated during registration to view the full patient profile, assigned doctor, and treatment status.

3. Calculating & Printing Bills

Select the Calculate & Print Bill tab. Enter the Appointment Number to automatically generate the invoice. The system merges standard consultation fees with specific treatment costs. Click Print Receipt to hand the physical copy to the patient.

Security Warning

Always click the Exit System button from the left menu before leaving the front desk to ensure unauthorized personnel cannot access patient records.
